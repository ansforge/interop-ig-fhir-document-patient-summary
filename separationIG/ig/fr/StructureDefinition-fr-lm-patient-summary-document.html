Modèle logique: Modèle logique métier - FR LM Patient Summary Document

URL officielle: https://interop.esante.gouv.fr/ig/fhir/fr-patient-summary/StructureDefinition/fr-lm-patient-summary-document Version: 0.1.0
Draft à partir de 2026-09-25 Nom computable: FRLMPatientSummaryDocument

Éléments d'en-tête et de corps d'une Synthèse Médicale (International Patient Summary) contenant l'ensemble des sections cliniques et administratives.

Utilisations:

  • Ce Modèle logique n'est utilisé par aucun autre profil dans ce guide d'implémentation

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
